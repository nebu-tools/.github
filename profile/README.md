Tools for academic-ish knowledge work: reading, reviewing, writing, and submitting.

- [Janus](https://github.com/nebu-tools/janus): extract structured data from PDFs, inspect the
  evidence, and compare or export the results.
- [Kittum](https://github.com/nebu-tools/kittum): auditable, AI-assisted systematic literature
  reviews, from the protocol to the final reports.
- [Nisaba](https://github.com/nebu-tools/nisaba): a self-hosted editor for writing Typst documents
  together.
- [tabellion](https://github.com/nebu-tools/tabellion): build G-BA dossier modules as Word files
  from Typst and R.
- [siglum](https://github.com/nebu-tools/siglum): cite sources in Word with a search box, as a
  replacement for EndNote's Cite While You Write.

All projects are AGPL-3.0 and experimental.
