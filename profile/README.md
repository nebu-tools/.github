Free tools for research writing: finding and screening the literature, reading data out of PDFs,
keeping references, and writing the document.

| Project | What it does |
| --- | --- |
| [Kittum](https://github.com/nebu-tools/kittum) | A workbench for systematic reviews that someone else can audit. It covers the protocol, search, screening, extraction, appraisal and reports, and keeps every decision in a signed ledger. |
| [Janus](https://github.com/nebu-tools/janus) | Reads typed values and table rows from PDFs and keeps the place on the page that each one came from. |
| [Nisaba](https://github.com/nebu-tools/nisaba) | A self-hosted editor for writing Typst documents together, with a live preview. |
| [Siglum](https://github.com/nebu-tools/siglum) | A Word add-in for citations. You type `@key` or search, and it keeps the numbers and the bibliographies current. |
| [Tabellion](https://github.com/nebu-tools/tabellion) | Builds Word documents from R and Typst. |
| [Pinakes](https://github.com/nebu-tools/pinakes) | A library for bibliographic references. It reads and writes RIS, BibTeX, PubMed and CSL-JSON and finds duplicates. Rust, with WASM and Python bindings. |

Several of the projects are being rebuilt and change quickly. Each README says what works today.

All projects are free software under the AGPL-3.0. The logos are stand-in sketches until
hand-painted ones replace them.
